# Škoda Storyboard demo — URL / block registry (measured)

*Date: 2026-09-25 · Scope: the 43-line M1 demo URL set (`docs/planning/skoda-m1-url-set.txt`, 42 unique pages + 1 alias) + shared chrome · Companion report: [`SKODA-DEMO-SWEEP-REPORT.md`](SKODA-DEMO-SWEEP-REPORT.md).*

**Method.** Every value below comes from a real render — `getComputedStyle` / `getBoundingClientRect` captured by `.migration/sweep/capture.mjs` (headless Chromium, 1440 and 390 px, `<main>` region; header/footer captured separately), never from screenshots. Source = `www.skoda-storyboard.com`; EDS = `main--demo--skoda-storyboard.aem.live` where the page exists (11 of 43 on 2026-09-25). Interaction states (mega-menu, mobile drawer, rails drag/click) were measured with scripted Playwright. Raw captures + per-group JSON: `.migration/sweep/` (not committed).

**Status legend (coverage).** `covered` = ticket + implemented + visuals match · `covered-visual-off` = implemented, measured drift · `covered-not-built` = ticketed, not implemented/imported · `gap-needs-ticket` = no ticket covers it · `deferred-by-decision` = explicitly deferred/dropped · `out-of-scope`.

**Corrections applied after the per-group pass (follow-up checks).**
- `embed` (PR #109) and `search` (#131) **are on `main`** (merged 2026-09-25 09:25Z). Rows citing "embed not on main" are superseded: YouTube/Vimeo render as `embed` on EDS; remaining work there is layout width (SKODA-821) and the Buzzsprout mapping on press releases.

Their hero/perex/"6 cards"/missing-Tags-heading/missing-band findings are **stale content — re-import first**, then re-measure. The Epiq and Epiq-5-reasons pages are current, so their findings are real.

- "Gap" rows re-checked against the backlog: the dark in-body highlight panel is one gap across 4 story groups (one ticket), the pull-quote is one gap across press releases + kits, the floating share control belongs to SKODA-215 (ticket file missing), and the listing media-card is partially covered by SKODA-608.
